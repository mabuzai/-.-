# 中国象棋 · 国风泼墨版

**全网最强 HTML5 中国象棋。** 软件初期为 H5 版本，现已有**飞牛版**、**Wallpaper 版**。人机对战、双人同屏、五万多局内置棋谱、两千五百道残局杀法，以及可随意摆弄的局势还原与本地战绩统计，全部塞进一个文件里。

> 当前版本：v1.5 ｜ 文件体积：约 29 MB（体积主要来自内嵌的实录落子音效，无需联网加载任何资源）
> 本仓库为 H5 版本：**单文件、零依赖、完全离线**，下载一个 `.html` 双击就能下棋。飞牛版与 Wallpaper 版见文末「其他版本」。

---

## 特性一览

### 对弈
- **人机对战**：三档难度（简单 / 普通 / 困难），可自由选择执红先手或执黑后手
- **双人对战**：同一块屏幕上两人轮流落子
- 新局、悔棋、提示（AI 代走一步）、音效开关一应俱全
- 走法高亮、将军与胜负提示、动画落子

### AI 引擎
- Negamax + Alpha-Beta 剪枝 + PVS（主要变例搜索）
- 搜索深度随难度递增，困难档单步思考约 2.5 秒
- 引擎跑在 **Web Worker** 里，思考时界面不卡顿；若浏览器不允许创建 Worker（例如部分 `file://` 场景），自动退回主线程同步搜索，功能不受影响

### 内置棋谱库（约 5.5 万局）
- 六大分类：**布局研究 / 大师指点 / 古谱排局 / 名家专辑 / 赛事欣赏 / 中残杀法**
- 可按**棋手、赛事关键词**搜索，分类浏览 + 序号直达 + 拖动快速定位
- 另附 **48 部棋书、2515 局**布局研究资料（含变着与注解）
- 回放控制：⏮ 回到开局 / ◀ 上一手 / ▶ 自动播放 / ⏩ 下一手 / ⏭ 跳到终局
- **人机续下**：从棋谱当前局面直接接手，和 AI 接着下
- 导入支持：中文记谱（炮二平五、马8进7、前车进一）、坐标记谱（h2e2）、PGN、FEN，以及象棋桥 `.cbr` 单局与 `.cbl` 棋库；支持导出本局

### 残局挑战
- **2500 道**杀局：入门 900 / 进阶 800 / 挑战 800
- 1～7 步连杀，你执红先行，限定步数内将死对方即过关
- 走错不判负，可悔棋重来；卡住时可用「提示」或「看答案」

### 局势还原（摆局）
- 点选棋子再点棋盘即可摆放，支持擦除、清空、恢复初始局面、红黑互换
- 摆好后选「轮到谁走」，可直接转人机对局或双人对局接着下
- 自定义局面采用**吃王规则**：将帅可同列照面，吃掉对方将帅才算赢

### 战绩统计
- 每局结果本地留存，可按今天 / 近 7 天 / 近 30 天 / 全部 / 自定义日期筛选，按胜、负、和分别查看
- 带柱状趋势图，支持一键清空记录

### 外观与音效
- **9 种棋盘材质**：经典木纹、黑檀雅致、墨玉沉香、朱砂红、玄铁冷灰、霓虹夜、水墨宣纸、国风泼墨、琥珀木
- **8 种界面配色**：琥珀金、冰蓝、幽紫、竹青、朱红、银灰、暖橙、樱粉（另有「跟随棋盘」自动取色）
- **10 种棋子刻法**：标准、浮雕、古典木纹、扁平、瓷釉、彩环、加粗、阳刻、阴刻、鎏金
- **6 种落子音效**：经典电子、木质落盘、清脆棋子、玉石相击、实录·象棋（推荐）、实录·明亮

### 使用体验
- Canvas 绘制，棋盘同时受可用宽度与高度约束，矮屏自动缩放，不会出现纵向滚动条
- 响应式侧栏布局，桌面与手机浏览器都能用；轻触或按 `F` 进入全屏
- 偏好设置、战绩记录均存于 `localStorage`，关掉浏览器也不丢

## 快速开始

**最省事的方式**：下载 `中国象棋_国风泼墨版.html`，双击用浏览器打开，完事。

```bash
git clone https://github.com/<你的用户名>/<仓库名>.git
cd <仓库名>
# 直接双击 HTML，或起个本地服务
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/中国象棋_国风泼墨版.html
```

无需 npm install，无需构建，没有后端。

> GitHub 不会在线预览超过 1 MB 的 HTML。想让别人直接试玩，建议开启 **GitHub Pages**（Settings → Pages → 选择分支根目录），或直接用 `raw.githubusercontent.com` 链接下载。

## 实现说明

| 项目 | 做法 |
| --- | --- |
| 文件形态 | 单个 HTML，内联 CSS 与 JS，无 CDN、无外链字体图片 |
| 网络请求 | 零。`fetch` / `XMLHttpRequest` 一个都没有 |
| 棋盘渲染 | Canvas 2D，木纹与墨色底纹均程序化生成 |
| AI 线程 | 引擎代码以 `Blob URL` 注入 Web Worker，主线程只收结果 |
| 棋谱压缩 | 着法按「合法着法索引」每手 1 字节存储，载入时用规则引擎无损还原 |
| 落子音效 | Web Audio；实录音色以音频数据内嵌，不发起任何请求 |
| 数据存储 | `localStorage`（偏好设置、对局战绩） |

## 浏览器支持

Chrome / Edge / Firefox / Safari 的近几年版本均可。建议桌面浏览器窗口宽度不低于 900px 以获得完整侧栏体验。

**已知限制**：单文件接近 29 MB，首次打开需要几秒解压与解析；以 `file://` 方式直接打开时，部分浏览器会禁用 Blob Worker，此时 AI 会退回主线程搜索，思考瞬间界面会短暂停顿，属预期行为。

## 其他版本

| 版本 | 形态 | 说明 |
| --- | --- | --- |
| **H5 版**（本仓库） | 单个 `.html` 文件 | 浏览器直接打开，跨平台、可离线、零依赖 |
| **飞牛版** | 飞牛 OS 应用 | 从 H5 版演进而来，适合装在飞牛 NAS / 飞牛系统上常驻使用 |
| **Wallpaper 版** | 动态壁纸 | 以壁纸形式运行，桌面即棋盘 |

三个版本同源同引擎，棋力、棋谱库与残局题库一致，区别只在运行载体。飞牛版与 Wallpaper 版的获取方式见项目主页。
